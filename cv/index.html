Projects

  • 2025.01 - 2026.05
    Chickpea Fusarium Wilt Detector — MSDS Thesis
    Development of Hybrid Lightweight CNN Integrating SqueezeNet and CBAM for Edge Deployment Using Multi-Data Sources. Published in Procedia Computer Science (Elsevier / ICCSCI 2026).
    • Designed a novel hybrid CNN (SqueezeNet v1.1 + CBAM) achieving 82.09% cross-domain accuracy on unseen Myanmar field test set — outperforming MobileNetV2, EfficientNet-B0, and ShuffleNet
    • Applied INT8 static quantisation: 3.31× model compression (final size: 0.870 MB) for real-time mobile inference with zero accuracy degradation
    • Benchmarked across 115 real Android devices via Google AI Edge Portal (worst-case CPU inference: 73.7 ms, compatible with 2 GB RAM / Android 9.0+)
    • Personally collected field dataset from Myanmar farming communities with expert agronomist annotation (inter-rater reliability with Cohen's κ)
    • Full statistical validation: Wilcoxon signed-rank test, two-proportion z-test with Wilson confidence intervals, McNemar's test, 5-fold stratified cross-validation
